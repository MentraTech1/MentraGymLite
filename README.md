# 🏋️ MentraGym Lite | نظام إدارة الصالات الرياضية 

![MentraGym Banner](https://img.shields.io/badge/Status-Active-success) ![License](https://img.shields.io/badge/License-Free-blue) ![PWA](https://img.shields.io/badge/PWA-Ready-purple)

**MentraGym Lite** هو نظام مجاني متكامل لإدارة الصالات الرياضية (Gyms)، يعمل محلياً بالكامل (Offline-First) داخل المتصفح بدون الحاجة لاتصال بالإنترنت أو خوادم سحابية. تم تصميمه ليناسب أصحاب الصالات الرياضية الذين يفضلون الاحتفاظ ببياناتهم على أجهزتهم الشخصية بخصوصية تامة.

---

## ✨ المميزات الرئيسية

- 📴 **أوفلاين 100%:** يعمل محلياً على جهازك ويحفظ البيانات في المتصفح.
- 👥 **إدارة المشتركين:** تسجيل الأعضاء، تتبع تواريخ بداية ونهاية الاشتراكات، وتنبيهات بالاشتراكات المنتهية.
- 💰 **السجل المالي (الخزينة):** تتبع الإيرادات والمصروفات، حساب صافي الربح، وتصدير التقارير (Excel / PDF).
- 🏋️ **مكتبة التمارين والخطط:** إضافة تمارين مقسمة حسب العضلة، وإنشاء جداول تدريبية مخصصة للمشتركين.
- ⏱️ **المتابعة الحية:** شاشة مخصصة للمدربين لتسجيل أوزان المشتركين أثناء التمرين مع مؤقت زمني.
- 🛡️ **نظام الصلاحيات (RBAC):** حسابات منفصلة (مدير، موظف استقبال، كابتن) بصلاحيات محددة لكل دور.
- 📱 **تطبيق PWA:** يمكن تثبيت النظام كبرنامج على الكمبيوتر (Windows/Mac) أو الهاتف (Android/iOS) ليعمل كتطبيق مستقل.
- 💾 **النسخ الاحتياطي:** نظام استيراد وتصدير (JSON) آمن جداً لحفظ البيانات واسترجاعها في أي وقت.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

تم بناء النظام بهندسة برمجية فريدة (Single Page Application) تعمل بدون `Webpack` أو بيئة بناء، مما يسهل تشغيله وتعديله:

- **الواجهة الأمامية (UI):** `HTML5`, `CSS3`
- **التصميم:** `Tailwind CSS` (عبر CDN) و `FontAwesome` للأيقونات.
- **إطار العمل (Framework):** `React.js 18` (باستخدام `Babel Standalone` لترجمة أكواد JSX حياً في المتصفح).
- **قاعدة البيانات (Database):** `IndexedDB` باستخدام مكتبة `Dexie.js` لإدارة البيانات محلياً.

## 📂 هيكلية المشروع (Folder Structure)

```text
MentraGym/
│
├── index.html               # صفحة الهبوط والتسويق للمشروع
├── subscriptions.html       # بوابة الدخول وتأسيس قاعدة البيانات
├── dashboard.html           # الهيكل الرئيسي للنظام (Shell)
├── Tutorial.html            # دليل الاستخدام والشرح المصور
├── database.js              # إعدادات قاعدة البيانات Dexie.js (الجداول والدوال)
├── manifest.json            # إعدادات الـ PWA لتثبيت التطبيق
├── sw.js                    # الـ Service Worker لعمل التطبيق Offline
│
└── pages/                   # المجلد السحري (الشاشات يتم تحميلها ديناميكياً)
    ├── main.js              # لوحة التحكم والإحصائيات
    ├── members.js           # إدارة الأعضاء
    ├── exercises.js         # مكتبة التمارين
    ├── plans.js             # الخطط التدريبية
    ├── tracking.js          # سجل التمارين والمتابعة
    ├── finances.js          # الخزينة والمصروفات
    ├── settings.js          # إعدادات الصالة وطاقم العمل
    └── backup.js            # النسخ الاحتياطي
